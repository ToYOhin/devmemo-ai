# Support

## Where to ask

- **Bug or reproducible regression:** use the Bug Report issue form in this
  repository.
- **Feature proposal:** use the Feature Request issue form in this repository.
- **Setup question:** review [README.md](README.md) and
  [README_AI.md](README_AI.md), then open an issue with the `support` label if
  the documentation does not answer it.
- **Security concern:** follow [SECURITY.md](SECURITY.md), not a public issue.

## Scope

Support here covers DevMemo AI additions. For Memos behavior that is unchanged
by this project, use the upstream Memos support and issue channels.

This is a small maintainer-run project. Support is best effort; no response-time
or compatibility guarantee is implied.
