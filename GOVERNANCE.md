# Governance

DevMemo AI is currently a maintainer-led open-source project operated by
[@ToYOhin](https://github.com/ToYOhin).

The maintainer decides roadmap, release readiness, security response, and
whether a proposal belongs in DevMemo AI or upstream Memos. Contributions are
evaluated for product scope, security, test coverage, documentation, and
upstream compatibility.

Material changes to authorization, storage, external data transmission,
provider defaults, or public APIs require an explicit proposal and review before
merge. The project may decline changes that expand the maintained support scope.
