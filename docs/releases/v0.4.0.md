## What's new since v0.3.0

- **Windows core installer:** a per-user, no-admin installer for the embedded
  Web UI and Memos core, with desktop/Start Menu shortcuts, local UI launch,
  upgrade handling, and uninstall that retains Memo data. Release packaging
  adds a setup EXE alongside the existing portable ZIP and SHA-256 checksums.
- **Administrator-managed Agent Providers:** Settings → AI → Agent Provider
  supports deterministic, OpenAI, DeepSeek, and approved local Ollama endpoints.
  The `agent-provider-config-v1` contract and authenticated internal API expose
  metadata and masked key state, never the raw key. Saved configuration
  overrides the environment for Evidence Answer and AgentRun only.
- **Encrypted credentials:** AI-owned SQLite stores AES-GCM-encrypted keys,
  using a separately supplied master key and HKDF-SHA256 derivation. Provider,
  model, and base URL are authenticated metadata. Remote use requires enabling
  the configuration and explicitly consenting to authorized Memo export.
- **Bounded Provider execution:** Evidence Answer fails closed on Provider
  errors. AgentRun accepts only `agent-run-project-summary-v1`, renders Markdown
  on the server, and explicitly marks deterministic fallback on timeout,
  request failure, or invalid output. Connection testing uses a fixed synthetic
  prompt. This adds a finalizer, not free-form Agent tasks or a worker.
- **Provider fixes:** first-time keyless Ollama saves work; SQLite connections
  close deterministically; the Provider limit remains 20 seconds. Only Evidence
  Answer, AgentRun execution, and connection tests have a 25-second BFF budget;
  metadata stays at 10 seconds and shorter caller deadlines take precedence.
- **Installer failure handling:** failed executable replacement or metadata
  setup restores the old executable when possible; failed rollback retains its
  backup. Failure to start the uninstall helper preserves uninstall registration.
  Executable rollback does not undo partial shortcut/registry changes: rerun
  the installer to repair them after resolving the error.
- **Security hardening:** encoded-separator/static-file regressions preserve
  `/api`, `/file`, and `/mcp` boundaries. Thumbnail dimension and metadata probes
  are bounded, malformed TIFF/original-file fallback is covered, and the imaging
  fork rejects unsafe palette access. Mermaid regressions cover adversarial XY,
  Radar, and Architecture inputs. Unresolved PRs are no longer auto-closed as stale.
- **Dependency refresh:** Echo 5.2.0, x/image 0.41.0, x/crypto 0.55.0, x/net 0.58.0,
  gRPC 1.83.2, CEL 0.29.0, go-archive 0.3.0, imaging fork 1.6.5, Mermaid 11.16.1,
  cryptography 50.0.0, and refreshed Web tooling/lockfiles including nanoid
  3.3.18 and undici 7.29.1 overrides. pytest 9.0.3 and pytest-asyncio 1.4.0
  support the expanded synthetic suites. Legacy AES-GCM credentials and tamper
  rejection were tested with synthetic fixtures across cryptography 46 and 50.

## Delivery scope and upgrade notes

**The Windows installer delivers core functionality only.** It does not bundle
Python AI Service, an Agent runtime, Qdrant, Ollama, models, or external Provider
credentials. A settings screen is not proof that those services are installed.
Use the separate, explicit opt-in [AI setup](../../README_AI.md) for Agent use.
Deterministic/memory defaults, disabled Agent/lifecycle defaults, Memos-owned
authorization, server-owned citations, and read-only fixed AgentRun tasks remain.
No background worker, Memo write-back, approval workflow, or multi-instance
production acceptance is added by this release.

On Windows, the default program directory is `%LOCALAPPDATA%\Programs\DevMemoAI`;
Memo data lives separately at `%LOCALAPPDATA%\DevMemoAI\data`. Upgrade and
uninstall preserve that data directory. Back up Memos data/attachments using the
[operations guide](../operations.md) before upgrading. v0.3.0 supplied a portable
ZIP, not this installer: an existing custom data directory is not automatically
migrated to the installer default. Do not overwrite or abandon it implicitly.

For optional AI deployments, keep the AI database and master-key backup separate;
do not regenerate `AI_AGENT_PROVIDER_MASTER_KEY` during upgrade. Lost/changed
keys require credential reconfiguration. Legacy summary/chat routes still use
environment settings. Go/Web/Python source and tooling upgrades require the
documented development environment, not an in-place single-dependency downgrade.
The Windows build is currently unsigned; disclose possible unknown-publisher /
SmartScreen prompts and verify checksums. Do not describe it as signed or endorsed.

## Final candidate isolated acceptance — all pending

Before distribution, use a disposable Windows user/VM with synthetic
Memos, an isolated profile/data directory, and no access to an existing install,
real data, or credentials. Run one operation at a time; no Docker, model runtime,
GPU, or real Provider is needed for core acceptance. Preserve candidate hashes
and results outside Git. Include actual UI/browser checks in that disposable
environment; mocked command tests are not a substitute.
