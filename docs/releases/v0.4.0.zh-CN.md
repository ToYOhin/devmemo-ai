## 相对 v0.3.0 的完整变更

- **Windows 核心安装器：** 当前用户安装、无需管理员权限，提供嵌入式 Web/Memos 核心、
  桌面与开始菜单快捷方式、本地界面启动、升级和保留 Memo 数据的卸载。发布打包链路在原有
  便携 ZIP 与 SHA-256 校验和之外增加 setup EXE。
- **管理员 Agent Provider 设置：** 设置 → AI → Agent Provider 支持 deterministic、OpenAI、
  DeepSeek 与受限本地 Ollama。`agent-provider-config-v1` 契约与认证内部 API 只返回元数据和
  掩码凭据状态，不返回原始 key。已保存配置只覆盖 Evidence Answer、AgentRun 的环境回退配置。
- **加密凭据存储：** AI 自有 SQLite 使用 AES-GCM 保存凭据，独立主密钥通过 HKDF-SHA256
  派生加密密钥；Provider、model、base URL 纳入认证元数据。远端调用需要同时启用配置并明确
  同意导出已授权 Memo 内容，连接测试只发送固定合成提示。
- **有界 Provider 执行：** Evidence Answer 在 Provider 出错时拒绝返回答案。AgentRun 只接受
  `agent-run-project-summary-v1`，服务端渲染 Markdown；超时、请求失败或输出不合约时，
  artifact 明确标记 deterministic 回退。这是报告终结器接入，不是自由任务 Agent 或后台 worker。
- **Provider 缺陷修复：** Ollama 首次保存允许无 key；SQLite 连接确定性关闭。Provider 截止时间
  保持 20 秒；只有 Evidence Answer、AgentRun 执行与连接测试的 BFF 预算为 25 秒，元数据
  请求仍为 10 秒，调用方更短的截止时间优先。
- **安装器失败处理：** 程序替换或元数据设置失败时尽可能恢复旧 EXE；回滚失败保留备份。
  卸载辅助进程无法启动时保留卸载注册信息。回滚不还原已部分修改的快捷方式/注册表，排除错误
  后需重新运行安装器修复。
- **安全加固：** 编码分隔符与静态文件回归覆盖 `/api`、`/file`、`/mcp` 边界；缩略图尺寸和
  元数据探测有界，覆盖损坏 TIFF 与原图回退，imaging 替代分支拒绝不安全调色板访问。
  Mermaid 覆盖恶意 XY、Radar、Architecture 输入；未解决 PR 不再由 stale 自动关闭。
- **依赖与工具链：** Echo 5.2.0、x/image 0.41.0、x/crypto 0.55.0、x/net 0.58.0、gRPC 1.83.2、
  CEL 0.29.0、go-archive 0.3.0、imaging 替代分支 1.6.5、Mermaid 11.16.1、cryptography 50.0.0，
  以及 Web 构建/测试依赖与锁文件更新，包括 nanoid 3.3.18、undici 7.29.1 overrides。
  pytest 9.0.3、pytest-asyncio 1.4.0 支持扩充后的合成测试；使用合成夹具验证了 cryptography
  46 到 50 的旧 AES-GCM 凭据兼容和篡改拒绝。

## 交付范围与升级说明

**Windows 安装器仅交付核心功能。** 不包含 Python AI Service、Agent 运行时、Qdrant、Ollama、
模型或外部 Provider 凭据；界面出现设置入口不代表相关服务已安装。Agent 必须通过独立、显式
opt-in 的 [AI 部署路径](../../README_AI.zh-CN.md) 使用。deterministic/memory 默认值、默认关闭
的 Agent/lifecycle、Memos 自有权限、服务端引用和固定只读 AgentRun 任务均保持不变。
本版本不增加后台 worker、Memo 写回、approval 流程或生产级多实例验收。

Windows 默认程序目录为 `%LOCALAPPDATA%\Programs\DevMemoAI`，数据目录独立位于
`%LOCALAPPDATA%\DevMemoAI\data`，升级和卸载保留该数据目录。升级前按
[运维指南](../operations.zh-CN.md) 备份 Memos 数据与附件。v0.3.0 提供便携 ZIP 而非此安装器；
原有自定义数据目录不会自动迁移至安装器默认目录，不能隐式覆盖或丢弃。

可选 AI 部署应分别备份 AI 数据库和主密钥，升级不要重新生成 `AI_AGENT_PROVIDER_MASTER_KEY`。
主密钥改变或丢失后需要重新配置凭据。旧 summary/chat 路由仍使用环境变量。Go/Web/Python
源码与工具链升级遵循开发环境文档，不能用单个依赖原地降级代替整体验证。
当前 Windows 构建未签名，应如实说明可能出现的未知发布者/SmartScreen 提示并核对校验和，
不能宣称已签名或已获认可。

## 最终候选包隔离验收——全部待执行

分发前使用一次性 Windows 用户/虚拟机、合成 Memo 和隔离配置/数据目录，不接触现有
安装、真实数据或凭据。每次只执行一项；核心验收不需要 Docker、模型运行时、GPU 或真实
Provider。候选包哈希和验收结果保存在 Git 外；真实界面/浏览器检查应在该一次性环境进行，
不能以模拟命令测试替代。

| 待验收项 | 同一个最终候选包必须提供的证据 |
| --- | --- |
| 身份与清单 | 完整源码 SHA、干净源码、内嵌 `0.4.0` 版本/commit、预期八个文件、归档布局、全部载荷 SHA-256。记录 setup EXE 字节；改名为 `DevMemoAI.exe` 后应与 ZIP 内程序载荷一致。 |
| 最终构建门禁 | 候选 SHA 的源码 CI 与发布打包结果，覆盖六个平台二进制及嵌入式 production Web；manual 版本和 Canary 不能冒充最终稳定包。 |
| 标准用户首次安装 | 无提权；实际检查 HKCU 已安装应用注册、版本/路径/卸载命令、桌面/开始菜单 COM 快捷方式，以及空格、中文、单引号路径。 |
| 核心启动与持久化 | 快捷方式启动已安装程序、绑定 loopback 5230 并打开本地界面；合成账号创建/登录，Memo 与附件保存、编辑、重启后读取及搜索；不暗中安装或启动 AI sidecar/运行时。 |
| 端口冲突与重复安装 | 隔离模拟监听器占用 5230 和重复 setup 时，记录实际可观察结果，不改坏数据或终止无关进程；排除冲突后重试。不能以创建进程成功代替启动健康。 |
